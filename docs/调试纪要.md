# 调试纪要（面试一页纸）

硬件：江协平衡车 · STM32F103C8T6 + FreeRTOS。锁定版本 **7H55**：可站立 + USART2 蓝牙遥控。方法：**分阶段实测、OLED 当示波器、一次只改一件事、有对照才留。**

## 1. 先让程序跑起来

| 现象 | 根因 | 改法 |
|------|------|------|
| 教程引脚对不上板 | PWM 实为 TIM2/PA0·PA1；编码 TIM3/TIM4；蓝牙 USART2/9600；OLED 与 MPU 不是同一 I2C | 以实物为准，不先调 PID |
| OLED 编不过 / 不亮 | 标准库头冲突；OLED 被接到 I2C2 | 江协 V2.0 + **PB8/PB9 软件 I2C**；MPU 走 PB10/11 |
| 屏冻在旧画面 | RTOS 未启动就开 UART 中断，蓝牙乱数据写空队列 → HardFault | 调度后再 `Receive_IT`；回调检查 `osKernelRunning` |
| 停在 `RTOS...` | C8 仅 20KB RAM，栈按「字」设成 4KB×2，任务创建失败 | CMSIS 栈按**字节**；控制/显示各 2KB |
| 蓝牙无反应 | 队列 `uint16_t`、波特率 115200、口用成 USART1 | 队列 1 字节；USART2 9600；超时 600ms 清目标 |

## 2. 极性与阶段：别把 F 当成 G

- 符号链（**禁止再翻**）：`ENC_*_DIR=-1`，`MOTOR_*_DIR=+1`，`AvePWM=-Angle.Out`，`PID_SPEED_SIGN=+1`。悬空前倾，轮应追重心。**7H51 翻速度符号 → 松手加速倒下。**
- `TEST_STAGE 1→7`：OLED → MPU → 编码 → 电机 → 蓝牙 → 悬空直立 → 地面三环。
- **F 只有直立环，放地上必倒**（轮一滑重心越偏越大）。F 过关：离地轻推能回正。地上站稳是 G 的速度环。

## 3. 站立：7F10 是基准，优化常更差

曾把「电机 = 直立 PWM + 速度 PWM」，两环打架猛抖。改为串级：`速度 Out → 角度 Target → PWM`（角 10ms / 速·转 50ms）。

| 对照 | 车上结果 | 结论 |
|------|----------|------|
| **7F10/15** 弱速度 + 冻 T + 阻尼×28 | 慢晃约 2s，最好 | **收回的基准** |
| 7F14 / 34 去阻尼或加强速度 | &lt;1s 一边倒 | 禁止 |
| 7F31~33 运行中改 Mid / 拧软启动 | 再启秒倒、掉电 | Mid 只上电采一次 |
| 7F21 `turn_trim=12` | 原地右拧 | 站立 `dif=0` |
| `motor_trim±3`、ofs 隔拍 | 更转 / 前冲 | trim=0，右轮 ofs=**2**（整数） |
| `mid_trim` 0 / 0.02 / ≥0.05 | 后倒 / **均衡** / 前倒 | 锁 0.02 |

站立留下：速度 `Kp=0.5/Ki=0.005/±1.5°`；`|Sp|>0.4` **冻 T**；阻尼 `(Sp-目标)×28/±32`；±22° 停机（满 PWM 会拉垮电池复位）。

## 4. 蓝牙：问题多半是「杆没进环」，不是符号反了

- 遥控不可关掉阻尼（一推就冲）；纯前后 `dif=0`；`|lv|<8` 才借左杆转向（防后退转圈）。
- 有前后才切强速度环 `1.5/0.03/±4°`；站立/纯左右仍 7F10。
- **7H53** 超速冻写成 `Sp>目标`（余量 0）：满杆目标只有 ~0.32，站立残留 Sp 或轻推立刻冻 T → **先动的杆无效**，车仍走原方向。
- **7H53 换向清角度 I**：第二下前后死、偏航。
- **7H55**：冻 T 用 `|Sp|>|目标|+0.4`；换向**只清速度 I**。已知限制：前进再拉后退约 2～3s 才跟上。

## 5. 手柄没加：PA15 一脚两用

nRF CSN 与 TB6612 **STBY 同为 PA15**。无模块却 Init/轮询 = 反复关电机。7H55 删除 nRF，STBY 保持高。

## 面试时三句话

1. 先打通外设和 RTOS 生命周期，再用屏确认数据进没进环。  
2. 站立靠弱速度串级 + 冻 T + 阻尼；对照回退，不叠加新项。  
3. 遥控「反了」先查目标是否被保护逻辑冻死，不翻整条符号链。
